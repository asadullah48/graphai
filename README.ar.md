# 📊 GraphAI — محرك تنسيق تدفقات العمل الموجهة (DAG)

> **تطبيق مرجعي بلغة Python وإطار FastAPI لتنسيق الوكلاء عبر مخططات موجهة غير دائرية (DAG): جدولة طوبولوجية، تنفيذ متوازي، بوابات موافقة بشرية (HITL)، إعادة محاولة بتراجع أسي، وعقدة اختيارية لنموذج لغوي محلي (Ollama).**

---

## ما هو هذا المشروع؟

يُمثّل GraphAI تدفق عمل تجاري متعدد الخطوات — هنا: طلب تسهيل تجاري — على شكل **مخطط موجه غير دائري (DAG)**، ويُنفّذه عبر محرك تنسيق صغير بدل سكربت خطي. الهدف إظهار الآليات التي تجعل أنظمة الوكلاء موثوقة عملياً، وليس بناء منتج إقراض حقيقي:

- **جدولة طوبولوجية**: لا تُنفَّذ أي عقدة إلا بعد اكتمال جميع اعتماداتها السابقة؛ الفروع المستقلة (تحليل الائتمان، فحص الاحتيال) تعمل بالتوازي.
- **بوابات موافقة بشرية (HITL)**: العقد عالية القيمة أو الخطورة تُعلَّق وتنتظر إجراء موافقة/رفض موثّق قبل استئناف التنفيذ.
- **إعادة محاولة بتراجع أسي مع تشتت عشوائي**: الأخطاء العابرة تُعاد محاولتها تلقائياً باستخدام `min(max_backoff, base · 2^attempt + jitter)` بدل فشل التشغيل كاملاً.
- **تكامل حقيقي واختياري مع نموذج لغوي**: عقدة تحليل الائتمان تستدعي نموذج [Ollama](https://ollama.com) محلي لتوليد السرد. Ollama مجاني وذاتي الاستضافة ولا يتطلب مفتاح API أو حساب فوترة، ولهذا اعتُمد بدل مزوّد مدفوع. إن لم يكن Ollama يعمل (كما في العرض المباشر المستضاف أو في CI) تعود العقدة تلقائياً إلى سرد محاكى ثابت — التدفق لا يتوقف أبداً بانتظار خدمة خارجية. راجع `graphai/core/llm_client.py`.

بقية طبقة النطاق (درجات الائتمان، فحص الاحتيال، التسوية) محاكاة عن قصد — جوهر هذا المشروع هو محرك التنسيق المحيط بها، وهو ما تختبره حزمة `tests/`.

## التشغيل محلياً

```powershell
git clone https://github.com/asadullah48/graphai.git
cd graphai
pip install -r requirements.txt
pip install -e .

python -m pytest tests -v

uvicorn graphai.server:app --host 127.0.0.1 --port 8010 --reload
```

- **الواجهة**: http://127.0.0.1:8010/
- **توثيق Swagger**: http://127.0.0.1:8010/docs

لتفعيل النموذج اللغوي الحقيقي:

```powershell
ollama pull llama3.2
ollama serve
```
