# 📊 منصة GraphAI: إدارة وتنسيق تدفقات العمل الموجهة (DAGs) والتحكم المؤسسي

> **إطار عمل رائد لتنسيق تدفقات عمل الوكلاء الأذكياء بالاعتماد على المخططات غير الدائرية الموجهة (DAGs) والتفريع الشرطي، والموافقات البشرية، وإعادة المحاولة التلقائية.**

---

## 🌟 المزايا المؤسسية الرئيسية

1. **تنسيق قائم على مخططات DAG**: تنفيذ المهام وفق علاقات الاعتماد الدقيقة والتفرع المتوازي مع دمج المسارات بدقة عالية.
2. **وكلاء حوكمة متخصصون**:
   - **`WorkflowAgent`**: إدارة مسار المهام وترتيب الأولويات والتنفيذ المتوازي.
   - **`ApprovalAgent`**: إيقاف المهام عند بوابات الامتثال الحساسة، وفرض التوقيعات الرقمية واستئناف العمل.
   - **`RetryAgent`**: معالجة الأخطاء العابرة تلقائياً عبر خوارزميات التراجع الأسي مع التشتت العشوائي (Jitter).
3. **موافقات بشرية تفاعلية (HITL)**: تعليق آمن للمعاملات ذات المخاطر العالية (المبالغ > 100 ألف دولار) لحين الاعتماد البشري.
4. **استوديو تفاعلي ثنائي اللغة**: واجهة زجاجية عصرية تدعم العربية (RTL) بالكامل مع عارض رسومي حي لعقد المخطط ومتابعة التنفيذ اللحظي.
